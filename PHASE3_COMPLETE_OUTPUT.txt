6. MASK CLASS SEMANTICS
-----------------------

Project quality mask:
- 0 = VALID
- 1 = CLOUD-EXCLUDED QUALITY CLASS
- 2 = NODATA

NODATA is never converted to valid or cloud.

SCL source class mapping:
- 0 no data -> NODATA
- 1 saturated or defective -> NODATA
- 2 dark area or shadow -> VALID
- 3 cloud shadow -> CLOUD-EXCLUDED QUALITY CLASS
- 4 vegetation -> VALID
- 5 bare soils -> VALID
- 6 water -> VALID
- 7 unclassified -> VALID
- 8 cloud medium probability -> CLOUD-EXCLUDED QUALITY CLASS
- 9 cloud high probability -> CLOUD-EXCLUDED QUALITY CLASS
- 10 cirrus -> CLOUD-EXCLUDED QUALITY CLASS
- 11 snow or ice -> VALID

Cloud-shadow handling:
SCL class 3 is genuinely available and is integrated conservatively into quality class 1. The project retains the three-class quality-mask contract; class 1 is documented as cloud-excluded and includes provider cloud-shadow pixels.

No cloud probability raster is claimed because SCL is categorical.
